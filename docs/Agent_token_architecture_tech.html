Monitoring playbook

  • Start the server: python3 scripts/dashboard-server.py → http://127.0.0.1:9787; this page auto-polls /metrics.json every 5s.
  • Attribution buckets: .raven/.model-session.json — raven_overhead.by_source names the emitting script; user_work.tier_counts shows SIMPLE/MEDIUM/COMPLEX/LOCAL_ONLY distribution.
  • Regression alarm: overhead-per-call > ~175 tok ⇒ a router is double-firing (run python3 tests/test_routing_matrix.py — 9 cases must pass).
  • Gate audit: docs/observations/security_log.md (SHADOW / SOFT-WARN / BLOCKED / OVERRIDE lines) and .raven/state/skill-invocations.jsonl markers.
  • Session receipts: Stop-event summaries in ~/RavenVault/sessions/.
