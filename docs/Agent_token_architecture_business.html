Why the gate exists, in money terms

A specialist session is a ~$0.01 investment. Before the gate, the model could take the ~$0.01 skill load or skip it and free-style — wasting the routing nudge and producing undisciplined output. The gate makes the investment stick: code cannot reach a commit unless the specialist actually ran. You pay nothing extra for that guarantee.

How to monitor (no engineering required)

  • Live dashboard — have your engineer run python3 scripts/dashboard-server.py, then open http://127.0.0.1:9787. Raven overhead and your work are metered in separate buckets.
  • The one number to watch — "Raven overhead per prompt." Healthy: under ~175 tokens. If it climbs, routing is double-firing — a defect, not a fee.
  • Session receipts — every session writes a summary to ~/RavenVault/sessions/ (opens in Obsidian).
  • Discipline audit — gate overrides are never silent; each one is logged with a countdown in docs/observations/security_log.md.
